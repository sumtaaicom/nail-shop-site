# nail-shop-site
웹 Claude Code 강의 예시 — 성수동 1인 네일샵 홈페이지

## 도담 네일 홈페이지

`index.html` 파일 하나로 된 한 페이지 홈페이지입니다. 별도 설치나 빌드 없이 브라우저로 열면 바로 보입니다.

구성: 히어로 · 이달의 아트 · 디자인 갤러리 · 가격과 소요 시간 · 샵 소개 · 예약 방법 · 오시는 길 · 자주 묻는 질문

인스타그램을 보고 찾아오는 손님이 첫 화면에서 디자인을 보고, 가격과 시간을 확인하고, 바로 예약하도록 순서를 짰어요.

- 휴대폰 화면 기준으로 디자인했어요 (320px 화면까지 확인).
- 휴대폰에서는 화면 아래에 **카톡 상담 / 인스타 / 네이버 예약** 버튼이 항상 떠 있어요.
- PC에서는 같은 내용이 넓은 화면에 맞게 보이고, 하단 고정 버튼은 숨겨집니다.

## 넣어야 할 사진 (15장)

사진은 `images/` 폴더에 넣어 주세요. 긴 변 1600px 이하, WebP나 JPG로 장당 300KB 안쪽이면 휴대폰에서도 빨리 떠요.
`index.html`에서 `<!-- 사진 N: ... -->` 주석 바로 아래의 `<span>…</span>`을 `<img src="images/파일이름.jpg" alt="사진 설명">`으로 바꾸면 됩니다.

| # | 파일 이름 | 내용 | 비율 |
| --- | --- | --- | --- |
| 1 | `hero.jpg` | 반응이 가장 좋았던 대표 디자인 손 클로즈업 | 가로 (2:1로 잘려 보여요) |
| 2 | `monthly.jpg` | 이번 달 샘플 디자인 | 4:5 |
| 3–5 | `daily-1~3.jpg` | 데일리·오피스: 원컬러, 누드톤, 프렌치 | 1:1 |
| 6–8 | `season-1~3.jpg` | 시즌·포인트: 계절 컬러, 포인트 아트 | 1:1 |
| 9–11 | `art-1~3.jpg` | 아트·스페셜: 파츠·스톤, 화려한 아트 | 1:1 |
| 12 | `director.jpg` | 원장이 시술하는 손 (얼굴 없어도 됨) | 4:5 |
| 13 | `interior.jpg` | 1인 시술대가 있는 샵 내부, 사람 없이 | 3:2 |
| 14 | `entrance.jpg` | 건물 입구와 계단, 1층 카페 간판이 보이게 | 3:2 |
| 15 | `og.jpg` | 카톡·인스타로 링크를 보낼 때 뜨는 대표 이미지 | 1200×630 |

촬영 팁: 자연광, 밝은 단색 배경. 갤러리 사진은 같은 배경과 조명으로 맞추면 통일감이 생겨요.
