# nail-shop-site
웹 Claude Code 강의 예시 — 성수동 1인 네일샵 홈페이지

## 도담 네일 홈페이지

`index.html` 파일 하나로 된 한 페이지 홈페이지입니다. 별도 설치나 빌드 없이 브라우저로 열면 바로 보입니다.

구성: 히어로 · 이달의 아트 · 디자인 갤러리 · 가격과 소요 시간 · 샵 소개 · 예약 방법(+ 예약 문의 폼) · 오시는 길 · 자주 묻는 질문

인스타그램을 보고 찾아오는 손님이 첫 화면에서 디자인을 보고, 가격과 시간을 확인하고, 바로 예약하도록 순서를 짰어요.

- 휴대폰 화면 기준으로 디자인했어요 (320px 화면까지 확인).
- 휴대폰에서는 화면 아래에 **카톡 상담 / 인스타 / 네이버 예약** 버튼이 항상 떠 있어요.
- PC에서는 같은 내용이 넓은 화면에 맞게 보이고, 하단 고정 버튼은 숨겨집니다.

## 예약 문의 폼

예약 방법 아래에 "네이버 예약이 어려우면 여기에 남겨 주세요" 폼이 있어요. 손님이 보내면 화면에 "문의가 접수됐어요"가 뜨고, 내용은 **Web3Forms**(폼 내용을 이메일로 보내 주는 무료 서비스)에 접근 키를 만들 때 등록한 이메일로 와요.

- 받는 항목: 이름, 연락처, 원하는 시술, 희망 날짜, 희망 시간, 지금 손톱 상태(젤 있음/없음), 참고할 디자인 설명, 개인정보 동의
- 사진은 폼으로 받을 수 없어서 카톡으로 보내 달라고 안내해요.
- 스팸 막기: 사람 눈에는 안 보이는 칸에 로봇이 체크하거나, 페이지를 열자마자 3초 안에 보내면 실제로는 보내지 않아요.
- 접근 키는 `index.html`의 `access_key` 한 곳에 있어요. 홈페이지에 공개돼도 괜찮은 키예요.
- 공개 전에 한 번 직접 보내 보고, 이메일이 잘 오는지 확인해 주세요.

## 자동 점검과 메뉴 추가 (Claude용 설정)

`.claude` 폴더에는 Claude가 이 홈페이지를 고칠 때 쓰는 설정이 들어 있어요. 홈페이지 화면에는 영향이 없어요.

- **작업 끝날 때 자동 점검** (`.claude/settings.json`, `.claude/hooks/check-site.py`): Claude가 일을 마칠 때마다 `index.html`에서 아래 세 가지를 찾아요. 문제가 있으면 Claude가 스스로 고치고, 사진 파일처럼 사용자만 줄 수 있는 것은 무엇이 필요한지 알려 줘요.
  - 눌러도 갈 곳이 없는 페이지 안 이동 링크(`#`로 시작하는 주소)
  - 적혀 있는데 실제로는 없는 사진 파일
  - 사진 설명(alt)이 빠진 사진
  - 직접 돌려 보려면: `python3 .claude/hooks/check-site.py index.html`
- **메뉴 추가 스킬** (`.claude/skills/add-menu/SKILL.md`): "메뉴 추가해 줘. 마그넷 젤, 1시간, 5만원"처럼 이름·시간·가격만 말하면 가격표에 같은 모양으로 한 줄 넣고, 예약 문의 폼의 "원하는 시술" 목록에도 넣어 줘요. 모르는 값은 지어내지 않고 빈칸과 TODO로 남겨요.

## 검색·공유 설정

네이버·구글에서 "성수동 네일샵", "성수 젤네일"로 찾을 때 잘 나오고, 카톡·인스타로 링크를 보낼 때 예쁘게 보이도록 넣어 둔 것들이에요.

- **검색 결과 제목과 설명**: `index.html` 맨 위 `<title>`과 `description`. 검색어(성수동 네일샵, 젤네일)를 앞쪽에 넣었어요.
- **공유 미리보기**: `og:`로 시작하는 줄들. 카톡·인스타로 링크를 보내면 제목, 설명, `images/og.jpg` 사진이 떠요.
- **검색엔진용 가게 정보**: `index.html`의 `<script type="application/ld+json">` 부분. 화면에는 안 보이고, 구글이 가게 이름·주소·전화·영업시간을 알아보는 데 써요.
- **`robots.txt`**: 검색엔진 로봇에게 "홈페이지 전체를 봐도 돼요"라고 알려 주는 파일.
- **`sitemap.xml`**: 검색엔진에 "이 주소에 페이지가 있어요"라고 알려 주는 목록. 서치어드바이저·서치 콘솔에 등록할 때 써요.
- **아이콘**: `favicon.svg`, `icon-192.png`(검색 결과·주소창), `apple-touch-icon.png`(아이폰 홈 화면에 추가했을 때).
- 홈페이지 주소가 정해지면 `[홈페이지 주소]`를 모두 바꿔야 해요(아래 표 참고).

## 디자인

부드러운 핑크·베이지 분위기예요. 색과 글꼴은 `index.html` 위쪽 `<style>` 안의 `:root` 부분에 모여 있어서 여기만 바꾸면 전체 색이 같이 바뀝니다.

- 제목 글꼴: 고운바탕 · 영문 장식 글꼴: Cormorant Garamond · 본문 글꼴: Pretendard
- 대표 색: 더스티 로즈 `#d99ca1`, 진한 로즈 `#97545e`, 아이보리 `#fdf8f5`, 베이지 `#f4ebe2`
- 글씨 색(`--muted`, `--accent-dark`)은 베이지·연핑크 바탕 위에서도 읽기 쉽도록 대비 4.5:1 이상으로 맞춰 두었어요. 글씨 색을 더 연하게 바꾸면 읽기 어려워질 수 있어요.
- 본문 글꼴은 화면에 나오는 글자 조각만 골라 받는 방식이라 휴대폰에서 빨리 열려요(글꼴 용량 약 4.5MB → 약 0.5MB).

## 사진 (15장 중 11장 들어감)

지금 사진은 강의 예시용 Unsplash 무료 사진이에요. 출처는 `images/CREDITS-unsplash.md`와 페이지 맨 아래에 적혀 있어요. 실제 가게라면 꼭 내 가게 사진으로 바꾸세요.

**사진이 저장되는 곳**
- `images/파일이름.jpg`: 올린 원본 사진 (홈페이지에서는 직접 쓰지 않아요)
- `images/web/파일이름-작은폭.webp`, `-큰폭.webp`: 홈페이지에 실제로 뜨는 가벼운 사진. 원본을 칸 비율에 맞게 가운데를 잘라 작은 것과 큰 것 두 가지로 만들었어요.
- 휴대폰은 작은 사진을, PC나 선명한 화면은 큰 사진을 알아서 골라 받아요. 첫 화면 사진 말고는 스크롤해서 가까워질 때 불러와요.
- 홈페이지 전체 사진 용량: 원본 그대로였다면 약 2.1MB인데, 지금 휴대폰 기준 약 180KB예요. (`og.jpg` 약 120KB는 공유 미리보기에만 쓰여서 홈페이지를 열 때는 받지 않아요)

**새 사진을 넣을 때**: 원본을 `images/`에 올리고 Claude에게 "사진 넣어 줘"라고 하면 같은 방식으로 줄여서 넣어 줘요.
직접 넣으려면 `index.html`의 `<!-- 사진 N: ... -->` 주석 바로 아래 `<span>…</span>`을 `<img src="images/파일이름.jpg" alt="사진 설명" loading="lazy">`로 바꾸면 돼요. 이렇게 하면 원본이 그대로 떠서 조금 무거워져요.
