# nail-shop-site
웹 Claude Code 강의 예시 — 성수동 1인 네일샵 홈페이지

## 도담 네일 홈페이지

`index.html` 파일 하나로 된 한 페이지 홈페이지입니다. 별도 설치나 빌드 없이 브라우저로 열면 바로 보입니다.

구성: 히어로 · 이달의 아트 · 디자인 갤러리 · 가격과 소요 시간 · 샵 소개 · 예약 방법 · 오시는 길 · 자주 묻는 질문

인스타그램을 보고 찾아오는 손님이 첫 화면에서 디자인을 보고, 가격과 시간을 확인하고, 바로 예약하도록 순서를 짰어요.

- 휴대폰 화면 기준으로 디자인했어요 (320px 화면까지 확인).
- 휴대폰에서는 화면 아래에 **카톡 상담 / 인스타 / 네이버 예약** 버튼이 항상 떠 있어요.
- PC에서는 같은 내용이 넓은 화면에 맞게 보이고, 하단 고정 버튼은 숨겨집니다.

## 디자인

부드러운 핑크·베이지 분위기예요. 색과 글꼴은 `index.html` 위쪽 `<style>` 안의 `:root` 부분에 모여 있어서 여기만 바꾸면 전체 색이 같이 바뀝니다.

- 제목 글꼴: 고운바탕 · 영문 장식 글꼴: Cormorant Garamond · 본문 글꼴: Pretendard
- 대표 색: 더스티 로즈 `#d99ca1`, 진한 로즈 `#9c5862`, 아이보리 `#fdf8f5`, 베이지 `#f4ebe2`

## 사진 (15장 중 10장 들어감)

지금 사진은 강의 예시용 Unsplash 무료 사진이에요. 출처는 `images/CREDITS-unsplash.md`와 페이지 맨 아래에 적혀 있어요. 실제 가게라면 꼭 내 가게 사진으로 바꾸세요.

**사진이 저장되는 곳**
- `images/파일이름.jpg`: 올린 원본 사진 (홈페이지에서는 직접 쓰지 않아요)
- `images/web/파일이름-작은폭.webp`, `-큰폭.webp`: 홈페이지에 실제로 뜨는 가벼운 사진. 원본을 칸 비율에 맞게 가운데를 잘라 작은 것과 큰 것 두 가지로 만들었어요.
- 휴대폰은 작은 사진을, PC나 선명한 화면은 큰 사진을 알아서 골라 받아요. 첫 화면 사진 말고는 스크롤해서 가까워질 때 불러와요.
- 홈페이지 전체 사진 용량: 원본 그대로였다면 약 2.1MB인데, 지금 휴대폰 기준 약 180KB예요.

**새 사진을 넣을 때**: 원본을 `images/`에 올리고 Claude에게 "사진 넣어 줘"라고 하면 같은 방식으로 줄여서 넣어 줘요.
직접 넣으려면 `index.html`의 `<!-- 사진 N: ... -->` 주석 바로 아래 `<span>…</span>`을 `<img src="images/파일이름.jpg" alt="사진 설명" loading="lazy">`로 바꾸면 돼요. 이렇게 하면 원본이 그대로 떠서 조금 무거워져요.
