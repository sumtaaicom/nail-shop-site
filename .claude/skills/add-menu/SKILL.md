# 가격표에 시술 메뉴 추가하기

사용자가 **메뉴 이름 · 소요 시간 · 가격**을 알려 주면 `index.html`의 `<section id="menu">` 가격표에 기존 줄과 똑같은 모양으로 한 줄 추가해요.
이 저장소의 `CLAUDE.md` 규칙(쉬운 한국어, 이모지 금지, 가게 정보 지어내지 않기, 너비별 확인)을 그대로 따라요.

## 1. 받은 정보 정리하기

| 항목 | 필수 | 받은 값이 없을 때 |
| --- | --- | --- |
| 메뉴 이름 | 꼭 필요 | 사용자에게 물어봐요. 이름 없이는 추가하지 않아요. |
| 소요 시간 | 필요 | 지어내지 말고 `약 [ ]`로 두고 TODO를 남겨요(아래 4번). |
| 가격 | 필요 | 지어내지 말고 `[확인 필요]`로 두고 TODO를 남겨요(아래 4번). |
| 짧은 설명 | 선택 | 사용자가 말한 것만 써요. 없으면 설명 없이 시간만 넣어요. 다른 메뉴에 있는 `기본 케어 포함` 같은 문구도 사용자가 말했을 때만 써요. |
| 들어갈 묶음 | 선택 | 아래 "묶음 고르기" 기준으로 고르고, 애매하면 사용자에게 물어봐요. |

- 이름·시간·가격을 그럴듯하게 바꾸거나 다듬지 않아요. 사용자가 말한 그대로 써요(띄어쓰기·가운뎃점 정도만 기존 표기에 맞춰요).
- 한 번에 메뉴를 여러 개 말하면 말한 순서대로 넣고, 마지막에 한꺼번에 확인·저장해요.
- 물어볼 것(묶음, 기본 케어 포함 여부 등)이 있으면 **한 메시지에 모아서** 한 번만 물어보고, 그때 "이렇게 넣을게요: 마그넷 젤 · 약 1시간 30분 · 60,000원"처럼 정리한 값도 함께 보여 줘요.
- 같은 이름의 메뉴가 이미 있으면 새로 추가하지 말고 "이미 있는데 가격·시간을 바꿀까요?"라고 물어봐요.

### 묶음 고르기

가격표는 `<div class="card menu-group">` 카드 세 개로 나뉘어 있어요.

- **핸드 젤**: 손톱에 하는 젤 시술(원컬러, 그라데이션, 아트 등)
- **풋 젤**: 발톱 시술(이름에 "풋"이 들어가는 메뉴)
- **케어 · 기타**: 케어 단독, 젤 제거, 그리고 연장 1개·파츠처럼 **손톱 하나 단위로 더하는 것**

애매하다는 건: 위 세 가지 중 어디에도 딱 맞지 않거나, 이름은 한 묶음 같은데 성격은 다른 묶음 같은 경우예요.
예: "젤 연장 풀세트"는 이름에 "연장"이 있지만 손톱 전체에 하는 큰 시술이라 핸드 젤일 수도 있어요. 이럴 땐 넣기 전에
"핸드 젤과 케어 · 기타 중 어디에 넣을까요? (제 생각엔 ○○가 어울려요)"처럼 추천을 붙여 한 번만 물어봐요.

새 묶음(예: "속눈썹")이 필요해 보이면 마음대로 만들지 말고 사용자에게 먼저 물어봐요. 만들기로 하면 기존 카드를 그대로 복사해서 `<h3>` 제목만 바꿔요.

## 2. 표기 방법 (기존 줄과 똑같이)

- **시간**: `약 1시간`, `약 30분`, `약 1시간 30분` 형식. "90분"이라고 들으면 `약 1시간 30분`으로 써요.
- **가격**: 숫자에 천 단위 쉼표 + `원`. 예: `45,000원`. "6만원" → `60,000원`, "6만 5천원" → `65,000원`. "~부터", "이상"이면 `70,000원~`. 무료면 `무료`.
- **설명**: 시간 뒤에 ` · `(앞뒤 띄어쓰기 + 가운뎃점)로 이어요.

## 3. 넣을 HTML

해당 묶음의 `<ul class="menu-list">` 맨 아래(`</ul>` 바로 위)에 넣어요. 사용자가 위치를 말하면 그 자리에 넣어요.

시간과 설명이 모두 있을 때:

```html
            <li><span class="name">메뉴 이름<span class="desc"><span class="time">약 1시간</span> · 짧은 설명</span></span><span class="price">50,000원</span></li>
```

설명 없이 시간만 있을 때:

```html
            <li><span class="name">메뉴 이름<span class="desc"><span class="time">약 1시간</span></span></span><span class="price">50,000원</span></li>
```

시간을 몰라 빈칸으로 둘 때(아래 4번)도 같은 모양에 `약 [ ]`만 넣어요:

```html
            <!-- TODO: '메뉴 이름' 소요 시간을 원장님께 확인 -->
            <li><span class="name">메뉴 이름<span class="desc"><span class="time">약 [ ]</span></span></span><span class="price">50,000원</span></li>
```

설명이 있으면 `약 [ ]` 뒤에 ` · 설명`을 똑같이 붙여요. 시간과 가격을 둘 다 모르면 주석 하나에 `소요 시간과 가격`으로 함께 적어요.

- 들여쓰기(공백 12칸)와 `<span>` 구조를 기존 줄과 똑같이 맞춰요. CSS는 새로 만들지 않아요.
- 줄은 `<li>` 하나로 한 줄에 써요.

## 4. 모르는 값이 있을 때 (TODO 남기기)

시간이나 가격을 받지 못했으면 화면에는 빈칸으로 보이게 하고 세 곳에 표시해요.

1. 화면: 시간은 `<span class="time">약 [ ]</span>`, 가격은 `<span class="price">[확인 필요]</span>`
2. 그 줄 바로 위에 주석: `<!-- TODO: '메뉴 이름' 소요 시간(또는 가격)을 원장님께 확인 -->`
3. `README.md`의 "공개 전에 실제 정보로 바꿔야 할 것" 표에 한 줄 추가. 기존 줄과 같은 모양으로, "그라데이션 · 프렌치 소요 시간" 줄 바로 아래에 넣어요.
   예: ``| 마그넷 젤 가격 | `[확인 필요]` |``, ``| 젤 연장 풀세트 소요 시간 | `약 [ ]` |``

이미 있던 빈칸(예: 그라데이션 · 프렌치 `약 [ ]`)에 TODO 주석이 없더라도 이 스킬에서는 건드리지 않아요. 고치면 좋겠다고 사용자에게 제안만 해요.

## 5. 예약 문의 폼 목록도 맞추기

`index.html` 예약 문의 폼의 `<select id="f-menu">`(원하는 시술 고르기)에도 같은 이름을 `<option>메뉴 이름</option>`으로 넣어요.

- 넣는 자리: 같은 묶음의 메뉴들 바로 뒤. `젤 제거만`, `아직 모르겠어요 (상담 원해요)`는 항상 맨 아래에 둬요.
- 연장 1개, 파츠·스톤처럼 다른 시술에 **더하는 것**(가격이 "1개", "~" 단위로 붙는 것)은 폼 목록에 넣지 않아요(지금도 안 들어가 있어요). 그것만 받아도 되는 시술이면 넣어요.
- 넣었는지, 왜 안 넣었는지를 사용자에게 한 줄로 알려 줘요.

## 6. 그 밖에 맞춰야 할 곳

- 가격표 맨 위 안내문이 "모든 가격은 부가세와 기본 케어를 포함한 금액이에요"라서, 새 메뉴도 기본 케어가 포함된 것처럼 보여요. 사용자가 케어 포함 여부를 말하지 않았으면 "기본 케어도 포함인가요? 아니면 설명에 적어 둘게요"라고 확인해요. 포함이면 설명에 `기본 케어 포함`을 넣고, 아니면 사용자가 말한 대로(예: `케어 별도`) 넣어요.
- 가격표 밑의 안내(`<ul class="note">`), 다른 메뉴, 문구는 바꾸지 않아요.
- "이달의 아트"는 이 스킬로 이름을 바꾸지 않아요. 이달의 아트 섹션 교체는 따로 부탁받았을 때 해요.
- README의 "시술 가격 | 메뉴 섹션 전체" 줄은 그대로 둬요(메뉴 전체가 예시 값이라는 뜻이에요). 사용자가 "이건 실제 가격이야"라고 하면 그 사실을 사용자에게 다시 확인만 하고 README는 건드리지 않아요.

## 7. 확인하고 알려 주기

1. 점검 스크립트 실행: `python3 .claude/hooks/check-site.py index.html` → "문제 없음"이 나와야 해요.
2. Playwright로 **320px, 390px, 1280px** 너비에서 확인해요.
   - 전체 화면 스크린샷(`fullPage: true`)을 찍고, 가격표 부분만 잘라서 봐요. `#menu` 요소만 찍으면 위쪽 메뉴바와 아래 고정 버튼이 사진 위에 겹쳐 찍히는데, 이건 화면 문제가 아니에요.
   - 메뉴 이름이 길어 가격이 밀리거나 가격 글씨가 두 줄로 깨지지 않는지
   - 가로 스크롤: `document.documentElement.scrollWidth`가 화면 너비와 같아야 해요.
   - 휴대폰(320·390)에서는 아래 고정 버튼이 보이고, 페이지 맨 아래까지 내렸을 때 마지막 내용을 가리지 않는지. PC(1280)에서는 숨겨지는지
3. 사용자에게 쉬운 한국어로 짧게 알려 줘요.
   - 어느 묶음 몇 번째에 어떤 모양으로 들어갔는지 (예: "핸드 젤 맨 아래에 '마그넷 젤 · 약 1시간 · 55,000원'으로 넣었어요")
   - 예약 문의 폼 목록에 넣었는지
   - 빈칸으로 남긴 값이 있으면 무엇을 알려 주면 되는지
   - 필요하면 가격표 부분 스크린샷을 보여 줘요.
4. 작업 브랜치에 변경 내용을 저장(커밋)해요. 한 번에 받은 메뉴는 한 번에 저장해요. 메시지는 한국어로, 예: `가격표에 '마그넷 젤' 메뉴 추가`, `가격표에 '마그넷 젤', '젤 연장 풀세트' 메뉴 추가`
